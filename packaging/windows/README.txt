Gradius for PC (unofficial)
===========================

The game itself is not included. You need your own copy of Gradius for
the NES, European version, as a .nes file.

How to play
  1. Keep this whole folder together, somewhere you can save files
     (Documents or Desktop, not Program Files).
  2. Double-click gradius.exe. If Windows shows a blue warning, click
     "More info" and then "Run anyway".
  3. Drag your .nes file onto the game window, or press Enter to look for it.
  4. Wait a moment while the game gets ready. You only do this once.

Controls
  Move           Arrow keys      D-pad or left stick
  Fire           Z or Space      A
  Use power-up   X               B
  Start/pause    Enter           Start
  Options        Esc             Back or Guide
  Full screen    F11

To use a different .nes file, close the game and delete gradius.pak from
this folder.
